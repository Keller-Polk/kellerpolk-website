Compilers · Interpreters · Machine learning

I build language tools.

I'm Keller Polk. My work lives at the bottom of the stack: a compiler that lowers a C-like language to native machine code through LLVM, an interpreter for a small BASIC-style language, and a model that paints over your photographs. Each one is a real, working program — and each one has a page on this site where you can try it without installing anything.

01 Projects

Three tools, three pages

The first two run on the machine serving this page; the third runs in the cloud on Hugging Face.

01

The LLVM compiler

A C-like language — variables, functions, recursion, pointers, arrays — compiled by a Rust toolchain on top of LLVM 18 into a native binary that runs fresh on every try.

02 Source

Everything above is open source

  • llvm-compiler Lexer, parser, and code generator for the C-like language, written in Rust on top of LLVM 18.
  • apcsp-interperter A parser and interpreter for the APCSP language, written in Rust.
  • img-to-art The image-to-painting prototype, hosted as a Hugging Face Space.
  • kellerpolk-website This site, and the small server that runs the two local playgrounds.

Built with Rust and LLVM. No frameworks — a few hundred lines of plain HTML, CSS, and JavaScript.

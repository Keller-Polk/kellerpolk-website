Compilers · Interpreters · Tools

I build language tools.
Here are three you can try.

Each of the programs below is a real piece of software I wrote: a compiler that turns a C-like language into native machine code through LLVM, an interpreter for a small BASIC-style language, and a model that paints over your photos. No installs, no setup. Paste some code, press run, see what happens.

01 Playgrounds

Try them here

The first two run on the machine serving this page. Edit the code, press Run. The third lives on Hugging Face and is embedded below, so it runs in the cloud.

The LLVM compiler

A C-like language — typed variables, functions, recursion, pointers, arrays, if/else — that compiles to a real native executable using LLVM 18, then runs it. The binary is produced fresh for every run.

Output appears here.

The APCSP interpreter

A small BASIC-style language — procedures, input, random numbers, and loops — interpreted in Rust. Programs start at PROCEDURE start(). Type your program's input in the box below the source.

Output appears here.

Image to art

Upload a photo and it comes back as a painting. This one is a machine-learning prototype hosted on Hugging Face, embedded live.

Everything above is open source

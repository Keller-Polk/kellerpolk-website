The APCSP interpreter

A small BASIC-style language — procedures, input, random numbers, and loops — interpreted in Rust. Programs start at PROCEDURE start().

Output appears here.

The sample plays a guessing game — its secret number is 5, so type 5 in the input box to win (or type anything else to hear the other branch).

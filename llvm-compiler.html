The LLVM compiler

A C-like language — typed variables, functions, recursion, pointers, arrays, if/else — compiled to a real native executable using LLVM 18, then run. The binary is produced fresh for every run; nothing is cached between tries.

Output appears here.

The sample prints fib(10) and fib(15) — expect 55 and 610. Compile and run happen on the machine serving this page.
